Designed and developed an interactive Excel dashboard to analyze a chocolate company's sales performance across products, salespeople, and countries. The dashboard provides actionable insights through KPI cards, PivotTables, PivotCharts, slicers, heatmaps, scatter plots, and map visualizations. It enables users to monitor revenue trends, evaluate salesperson performance, compare product sales, and assess country-wise business contributions for data-driven decision-making.

Key Features:

Executive dashboard with key sales KPIs
Product, Salesperson, and Global Insights pages
Interactive slicers for dynamic filtering
Revenue, boxes shipped, and contribution analysis
Geographic sales visualization using Excel Maps
Revenue vs. Boxes Shipped performance analysis

Tools & Skills: Microsoft Excel, PivotTables, PivotCharts, Slicers, Conditional Formatting, Excel Maps, Data Visualization, Dashboard Design, Business Analytics, Data Analysis
